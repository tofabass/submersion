# Submersion

Submersion turns a still image into depth-layered parallax with 3D kaleidoscope symmetry. Full and Lite modes, oscillators, a layer stack, Look presets, stills and loop recording, all running in the browser with no install and no server.

**Live:** https://tofabass.github.io/submersion/

## Running it

Open `index.html` in a modern browser, or visit the live URL. Everything is in that one file. Fonts load from Google Fonts.

## Notes

- Look presets and interface settings are stored in your browser's localStorage. Use Export to keep a backup file.
- Projects are saved with Export file and opened with Import file.
- Stills and loop recordings download as normal files.
- `assets/` is reserved for sample-scene images.
